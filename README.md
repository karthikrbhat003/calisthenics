## ✍️ How to Log a New Session

### Option A: Logging with Text
1. Copy the [workout_template.md](templates/workout_template.md) file.
2. Navigate to the appropriate year, month, and week folder. If the folder doesn't exist yet, create it.
3. Paste the file and rename it as `YYYY-MM-DD.md` (e.g. `2026-08-10.md`).
4. Fill out the sections: Warm-up, Main Workout, and reflection notes.

### Option B: Uploading photos of your handwritten notes
1. Take a picture of your handwritten workout.
2. Save it in the weekly folder (e.g. name it `YYYY-MM-DD_workout_raw.png`).
3. Create the corresponding Markdown log `YYYY-MM-DD.md`.
4. Embed the image at the top of the file using standard markdown:
   `![Handwritten Note](YYYY-MM-DD_workout_raw.png)`
5. Transcribe the details or ask your AI partner (Antigravity) to convert it to a beautifully formatted table for clean reading and tracking!
